1. Prinsip Inti Arsitektur Final CORE INVARIANTS
1. Single Root Build Gradle

Seluruh domain modul dikelola di bawah 1 file build.gradle.kts di root project. Menghilangkan beban dependency multi-project Gradle pada tim 3 sampai 5 orang.

2. Etalase Publik client/ Standar

Setiap modul menyediakan etalase resmi client/ berisi interface kontrak dan Java 21 Record DTO. Modul lain dilarang mengimpor kelas internal implementasi.

3. Penegakan Batas Keras via ArchUnit

Batas antar modul dijaga secara otomatis oleh pengujian unit arsitektur pada ArchitectureTest.java yang berjalan di setiap kompilasi CI build.

4. Zero JPA Entity Leakage

Entitas JPA (@Entity) terkunci rapat di dalam modul. Seluruh data keluar wajib berupa Record DTO immutable yang dipetakan via MapStruct.

2. Peta Layer Arsitektur Monolith LAYER BOUNDARY
LAYER 1: WEB & CONTROLLER (PUBLIC API) REST ENDPOINT
Menyediakan REST endpoint untuk Web dan Mobile Client. Menerapkan YAVI input validation, penanganan error terstandar via RestResponse<T>, dan OpenAPI documentation.
ARCHUNIT ENFORCEMENT SHIELD (PEMBATAS ANTAR MODUL)
LAYER 2: MODUL BISNIS OTONOM (DOMAIN MODULES) DECOUPLED DOMAINS
Domain independen (identity, pm.board, platform.tenant). Komunikasi antar modul HANYA melalui client/contract/ via Constructor Injection.
LAYER 3: DATA STORAGE & MULTI-TENANCY RLS POSTGRESQL & REDIS
PostgreSQL Row Level Security (RLS) di level engine basis data, session setting app.tenant_id, dan cache Redis dengan isolasi prefix tenant.
Prinsip Isolasi Layer: Setiap layer berkomunikasi secara strictly hierarchical. Modul di Layer 2 dilarang mengakses langsung data layer atau repositori internal modul lain.

2. Peran Folder Etalase Publik (client/) AKSES TERBUKA
client/contract/: Interface Java publik murni. Bebas dari Spring annotation bisnis dan bebas JPA. Menjadi kontrak resmi yang di-injeksi modul lain.
client/dto/: Java 21 Record DTO. Bersifat immutable, serializable, dan hanya membawa data primitif atau value object aman lintas modul.
client/impl/: Class @Component privat. Mengimplementasikan method interface contract dengan memanggil service internal domain.
3. Peran Folder Domain Privat (<feature>/) TERKUNCI RAPAT
entity/ (JPA Entities): Dilarang keras keluar dari package domain. Tidak boleh dikembalikan ke modul lain.
repository/ (Spring Data JPA): Hanya dipanggil oleh service di domain lokal. Dilarang query langsung dari modul pemanggil.
service/ (Core Business Logic): Eksekusi proses bisnis internal domain. Akses dari luar wajib melalui client/contract/.
mapper/ (MapStruct): Mengonversi Entity JPA internal menjadi Record DTO pada client/dto/ secara single-pass.

2. Standar Keamanan & Multi-Tenancy DEFENSE IN DEPTH
1. PostgreSQL Row Level Security (RLS)

Isolasi data di engine database via tenant_id = platform.current_tenant(). Session database diatur per transaksi: SET LOCAL app.tenant_id = ....

2. Prinsip Fail-Closed

Jika sebuah request mengakses data bertingkat tenant tetapi activeTenantId kosong, request ditolak seketika dengan status HTTP 403 Forbidden.

3. Cache Tenant Prefixing (Anti-Bypass)

Setiap cache key tenant wajib menyertakan tenant ID: key = "#tenantId + ':' + #id" untuk mencegah tenant lain membaca data memori.

4. Zero Secret Exposure & UU PDP

Kredensial wajib dibaca dari environment variables. Data pribadi (PII) dilarang bocor ke log aplikasi atau error stack traces.
